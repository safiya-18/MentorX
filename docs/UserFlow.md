# MentorX User Flow

## First Launch

1. Welcome Screen
   - App introduction
   - "Let's Begin"

↓

2. User Registration
   - Name
   - Email
   - Password

↓

3. GATE Setup
   - Branch (CSE, ECE, EE, ME, CE...)
   - Target GATE Year
   - Daily Study Hours
   - Current Preparation Level
     - Beginner
     - Intermediate
     - Advanced

↓

4. Dashboard

Displays:

- Today's Mission
- Study Progress
- Remaining Days
- Study Streak
- Weekly Goal

↓

5. Study Session

Choose Subject

↓

Choose Topic

↓

Start Focus Timer

↓

Mark Topic Complete

↓

Update Progress

↓

6. Revision

MentorX recommends

- What to revise
- How much time to spend
- Which topics are weak

↓

7. Weekly Review

Every Sunday

- Mock Test
- Score Analysis
- Weak Topics
- Strong Topics
- Next Week Plan

↓

Repeat Daily Until GATE
